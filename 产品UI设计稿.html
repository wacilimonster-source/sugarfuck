现状诊断（上图为 MuMu 实机）

  • 1底栏 / 火焰 / 箭头全是彩色 emoji，风格杂、显廉价
  • 2空态是大灰块，没有图标与虚线框，像占位符没做完
  • 3欢迎卡是绿色 ✓——勾号是"完成"语义，首用场景不搭
  • 4卡片全平无投影，白卡和大背景糊在一起，没有层次
  • 5标题、标签、数值层级弱，缺设计感细节

本轮产品优化（V2.2）· 聚焦核心 核心链路 = 记 → 看 → 规律；这一轮围绕"记"压缩步骤

01 修正
＋按钮数学居中：五槽对称底栏

原布局 [今天][趋势][＋][我的] 四格等宽，＋落在 62.5% 处显得歪。改为 [今天][趋势][＋记录][提醒][我的] 五槽——左右各两格等宽，＋严格居中；并在下方加"记录"文字，第一眼就懂这是最主要的动作。

02 聚焦
提醒升级为一级 Tab

定时提醒是安卓版最核心的差异能力，原先藏在"我的 → 提醒设置"两层里。提到底栏后一点即达（查看/开关/改时间/可靠性检查）；"我的"页同步移除该项，更精简。

03 提速
提醒卡"一键补记"

首页提醒卡里没记的时段（如空腹）从纯文字改为可点胶囊「＋空腹」：点一下直接进入录入页、并把该时段预选好——核心链路 3 步减为 2 步（点胶囊 → 输数值 → 保存）。
