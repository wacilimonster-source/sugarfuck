一、产品概述

1.1 背景与定位

65 岁以上的血糖监测人群面临三重障碍：记不住、看不清、不敢用。此前方案为微信小程序，但个人自用场景下需要注册、审核、备案，且平台限制无法做定时提醒、无法直接分享文件——成本与收益不匹配。糖记改为安卓原生 APP，侧载安装，不注册、不上架、不备案：两步完成一条记录（大号数字键盘输数值 → 大按钮选时段 → 保存），每日定时通知提醒，数据存本机且可导出文件备份，打开即见大字趋势。

糖记是个人自用的记录与回顾工具，主要用户为 65 岁以上人群（驾驶员本人或其长辈），单机单用户。它不是医疗器械，不提供任何诊断或用药建议。

1.2 目标与非目标

目标（V2.0）非目标
· 65+ 用户独立完成两步录入 ≤ 30 秒，无需他人协助
· 全界面符合适老化规范（第五章：字号/触控/对比度）
· 数据本机持久保存；导出文件可分享到微信/存档；换机可导入恢复
· 每日定时系统通知提醒（≤2 条，可关）＋首页软提醒兜底
· 趋势折线、时段均值、达标比例，大字呈现
· 目标范围可自定义（遵医嘱个性化）
· 给医生：复制文本 ＋ 生成 CSV 文件一键分享 		· 不做 iOS 版、不上应用商店（侧载自用）
· 不做账号体系、云同步、多设备同步
· 不做诊断、用药建议，不计算剂量
· 不做多人 / 家庭共用（家人远程查看需云，列入 Growth Tracks 缓行）

· 不做"标准版+大字模式"双版本（全量适老化单一版本）

1.3 用户与使用场景

用户：65 岁以上血糖监测者，使用安卓手机（Android 8.0+），会基础触屏操作，视力可能有老花，可能伴有手指灵活度下降；每日测量 1–4 次；希望长期坚持记录并在复诊时向医生展示数据。

  • 场景 A · 顺手记录：晨起测空腹 6.2，点开糖记 → 点 ＋ → 大键盘按 6.2 → 下一步（时段已自动选中"空腹"）→ 保存，全程两步，约 20 秒。
  • 场景 B · 补记：上午忘记录入，午饭后补记早餐后数值，在"更多选项"里把时间改到上午 9 点。
  • 场景 C · 提醒：早上 7:00 手机通知（"该测空腹血糖啦"）→ 点通知直接打开 APP 录入。
  • 场景 D · 回顾：晚上打开"趋势"页，看大字统计卡（平均血糖 / 达标比例 / 最高最低）和折线走势。
  • 场景 E · 就诊：复诊前点"导出数据"→ 生成文件 → 微信发给医生，或点"复制全部数据"直接粘贴。
  • 场景 F · 换手机：旧机导出文件发到新机 → 新机安装 APP → 导入文件 → 数据全部恢复。

1.4 核心循环

1定时通知提醒 → 2测血糖 → 点开 APP 点 ＋：大键盘输数值（第 1 步）→ 大按钮选时段（第 2 步，已自动推荐）→ 保存 → 3本机保存 → 4首页即时反馈（达标绿 / 偏低橙 / 偏高红 + 文字）→ 5累积后看趋势、时段均值、达标比例 → 强化记录动机，回到 1

状态源：本机 Room 数据库为唯一权威数据源；无网络依赖；数据不出手机（除用户主动导出/分享）。

三、功能需求详述

FR-1 血糖记录管理 P0

两步录入流程

  • 第 1 步 · 输数值：大号数字键盘（每键 ≥60dp 高、≥26sp 字），键位 1–9 / 0 / 小数点 / 删除；输入区 ≥60sp 显示；下方展示最近 3 个常用值大按钮（一键填入）。输入合法（1.0–33.3，最多 1 位小数）后"下一步：选时段"亮起。
  • 第 2 步 · 选时段并保存：顶部汇总条（大字数值 + 实时判定标签）；2 列 × 4 行大按钮（每个 ≥64dp 高、≥20sp 字）选时段，按当前时间自动推荐并预选（标"推荐"角标）；多数情况直接点"保存"完成。
  • 更多选项（折叠）：测量时间修改（补记用）与备注（≤200 字）默认收起，点"更多选项"展开；主流程不被干扰。

字段规则

字段类型 / 规则说明
血糖值数字，1.0–33.3 mmol/L，1 位小数自定义键盘天然限制格式；超范围禁止进入第 2 步并明确提示
时段标签8 选 1，必选自动推荐（预选 + "推荐"角标），可改，见 FR-2
测量时间日期时间，默认当前时间折叠于更多选项；不允许未来时间（容差 1 分钟）
备注文本，可选，≤ 200 字18sp 输入框，折叠于更多选项

操作规则

  • 新增：保存即写入本机数据库，成功后 Toast"记好了，继续保持 ✓"（3 秒），返回并刷新页面。
  • 编辑：点击记录行打开录入页（预填原值），两步走完保存；按新测量时间重新排序。
  • 删除：编辑态底部"删除这条记录"大按钮，系统确认对话框二次确认后删除，不可恢复。
  • 重复时段：同一天同一时段允许多条记录（复测场景）。

FR-3 目标范围与颜色反馈 P0

  • 默认值：空腹 4.4–7.0 mmol/L、非空腹 4.4–10.0 mmol/L（参照《中国 2 型糖尿病防治指南》一般控制目标），可在"我的 → 目标范围设置"修改。
  • 校验：每端 1.0–25.0，下限 < 上限，保留 1 位小数；非法输入禁止保存并提示。
  • 颜色规则（颜色+文字双编码）：● 达标 绿色；● 偏低 橙色；● 偏高 红色；状态色一律用加深版（见第五章）。应用于：第 2 步实时判定、记录列表圆点与数值、趋势图数据点、时段均值条。
  • 修改目标后，全量历史记录与统计即时按新目标重新判定。

FR-4 统计分析 P0

指标口径定义
平均血糖所选范围内全部记录的算术平均，1 位小数
达标比例（即 TIR）达标记录数 ÷ 总记录数 × 100%，按各自时段目标判定；取整。UI 用口语"达标比例"，副注"在目标范围内的次数占比"，不出现 TIR 缩写
最高 / 最低极值记录，合并为一张卡展示，点数据点或看明细可见时段与日期
各时段平均8 个时段分别的算术平均与次数；条形颜色按该时段目标判定；无数据显示"还没记过"
趋势折线x 轴时间、y 轴 mmol/L；每条记录一个着色数据点（点击下方显示明细），折线为日均值连线；绿色背景带为非空腹目标区间，虚线为空腹上限；轴标签 ≥13sp
连续记录天数按自然日向前连续有 ≥1 条记录的天数；今天尚无记录时从昨天起算（不因"今天还没测"清零）
范围切换近 7 / 30 / 90 天（自然日，含今天）；分段按钮 ≥56dp 高

FR-5 软提醒 P0

  • "今天"页顶部提醒卡：列出当前时间已过截止点且今日无记录的时段，如"还有 2 个时段没记：空腹、早餐后"；全部记完显示绿色鼓励卡。
  • "随机"时段不参与提醒；持续记录天数徽章共同构成坚持激励。
  • 软提醒永远开启（无需权限），是系统通知的兜底。

FR-6 定时系统通知提醒 P0 V2.0 新增

项规则
条数最多 2 条每日提醒（如 07:00"该测空腹血糖啦"、21:30"睡前别忘了血糖"）
每条组成开关 + 时间（小时:分钟）+ 文案模板（从 3–4 个预设口语短句选择，可自定义短文本）

点击行为点击通知打开 APP 落在"今天"页

FR-7 数据导出与导入 P0 V2.0 新增

  • 复制文本：生成制表符分隔文本（记录明细 + 汇总 + 当前目标），一键复制到剪贴板（沿用 V1 设计）。
  • 导出文件：生成 糖记-2026-10-08.csv（UTF-8 带 BOM，Excel/微信可直接打开），列：日期 / 时间 / 时段 / 血糖(mmol/L) / 判定 / 备注；末附汇总行。生成后调起系统分享面板（微信、邮件、文件管理器均可）。
  • 导入恢复：从文件选择器选 CSV → 校验表头与数值格式 → 逐条导入；去重规则：同 id 覆盖；无 id 时按（测量时间 + 数值 + 时段）完全一致判为重复跳过。导入前弹出预览"将导入 N 条（跳过重复 M 条）"确认。
  • 换机迁移：旧机导出 → 发送到新机 → 新机安装 APP → 导入。使用说明中给出三步图文。

FR-8 设置 P1

  • 目标范围设置：4 个大号数值输入（空腹/非空腹 × 下限/上限）+ 保存 + 恢复默认。
  • 提醒设置入口（见 FR-6）；通知权限与电池优化状态展示。
  • 数据管理：导出文件 / 导入文件 / 复制文本。
  • 版本信息；免责声明（≥14sp，口语化）常驻"我的"页底部。

四、页面详细设计

视觉基调整体遵循配套原型 产品设计原型.html V1.1（今天/趋势/我的/两步录入与其一一对应）；字号尺寸按 dp/sp 对应移植（见第五章）。新增页面按同一规范扩展。

4.1 今天页

  • 头部：左侧日期（23sp 粗体），右侧橙色徽章"🔥 连续 N 天"（16sp）。
  • 提醒卡：缺时段时米黄警示卡（大图标 + 19sp 标题 + 16sp 说明）；记完转绿色鼓励卡。
  • 最近一次大卡：测量时间（16sp）、72sp 大数值、时段 chip、状态标签（18sp，达标/偏低/偏高 + 对应目标区间）、备注。点击进入编辑。
  • 今日记录：按时间倒序，每行 ≥76dp 高 = 状态圆点 + 时段（18sp，+备注）+ 时刻与判定（16sp）+ 数值（28sp）；点击进入编辑。空态："今天还没有记录，测完血糖点下方 ＋"。
  • 近 7 天迷你趋势：日均值折线 + 目标区间底色，入口"看完整趋势 →"跳转趋势 Tab。

4.2 趋势页

  • 范围切换：近 7 / 30 / 90 天分段控件（≥56dp 高、17sp），默认 7 天。
  • 趋势折线卡：图高 ~250dp，轴标签 ≥13sp，数据点半径 5/3.5dp；点击数据点在图下方显示单条明细（16sp）。
  • 3 张统计卡：平均血糖 / 达标比例 / 最高最低，数值 27sp、标签 15sp；辅助行（16sp）"共 X 次记录 · 连续 Y 天 · 达标比例 = 在目标范围内的次数占比"。
  • 各时段平均卡：8 行水平条形（行高 ≥64dp、标签 17sp、数值 20sp），无数据时段显示"还没记过"。
  • 历史记录：按日分组倒序，默认最近 7 个有记录的日期，"展开更多记录"大按钮（≥56dp）切换，行样式与今日记录一致。

4.3 我的页

  • 账号卡：本地图标 + "糖友"+ "● 数据存本机"状态说明（无联网）。
  • 目标范围设置：展开行内编辑器（输入框 21sp、按钮 ≥56dp）。
  • 提醒设置：进入子页（4.4）。
  • 数据管理：导出文件（分享）/ 导入文件 / 复制全部数据（给医生）。菜单行高 ≥80dp、文字 18sp。
  • 关于：版本号；免责声明常驻底部。

4.4 提醒设置页 V2.0 新增

  • 提醒 1 / 提醒 2 两张卡：左侧大开关（≥60dp 触控），开启后显示大号时间（32sp，点击调起系统时间选择器）与文案模板选择（预设口语短句，如"该测空腹血糖啦 / 睡前别忘了血糖"）。
  • 推荐组合：一键套用"早 7:00 空腹 + 晚 21:30 睡前"。
  • 可靠性卡片：通知权限状态（未授予时红色提示 + "去开启"按钮）；"让提醒更可靠"按钮 → 跳转系统电池优化/自启动设置，附通用图文说明。
  • 文案全口语化，不出现"AlarmManager/权限 POST_NOTIFICATIONS"等术语（面向用户只说"通知权限"）。

状态表现

五、适老化设计规范

5.3 对比度与色彩

  • 正文与主要文字对白底 ≥ 7:1；次要文字 ≥ 5:1；禁止浅灰大段正文。
  • 状态色加深版：达标绿 #0e9c73（文字 #0a5c44）、偏低橙 #b45309（文字 #8a4106）、偏高红 #c53030（文字 #a02020）；永远"颜色 + 文字"双编码。
  • 色弱用户只看文字标签也能完整使用。

5.4 语言与文案

  • 不用英文缩写与专业黑话："达标比例（在目标范围内的次数占比）"代替"达标率 TIR"；提醒文案全部口语短句。
  • 提示语具体、面向动作："数值要在 1.0 到 33.3 之间，请重新输入"。
  • 医疗免责用口语："本工具只做记录和参考，不能代替医生诊断。"

5.5 交互与认知

  • 一步一件事：录入拆成两步，每步只有一个主要任务与一个主按钮。
  • 默认值优先：时段自动推荐并预选；提醒提供推荐组合一键套用。
  • 低频功能折叠：改时间、备注收进"更多选项"；提醒设置在子页。
  • 无手势依赖：全部功能点按可达，不使用滑动删除、长按、双击等隐藏手势。
  • 防误触与可恢复：删除必须二次确认；Toast 3 秒；主按钮置灰表达"不可点"。
  • 步骤可见：多步流程顶部常驻"第 X 步，共 2 步"。

九、验收标准（First Playable）

  1. 模拟器直接运行；release APK 在驾驶员真机安装成功。
  2. 核心循环（两步）：点 ＋ → 键盘输入 7.8 → 下一步 → 时段已推荐"早餐后"（或按时间推荐项）→ 保存 → 首页即时显示且颜色正确；杀进程重启数据仍在。
  3. 录入第二条后趋势图出现两个数据点；7/30/90 天切换正常。
  4. 种子数据下：达标比例 / 时段均值 / 平均 / 最高最低与手工核算一致（对拍表）。
  5. 编辑与删除：改数值后列表与统计刷新；删除有二次确认。
  6. 目标范围：改为自定义值后，全部颜色与统计即时变化；非法输入被拦截。
  7. 提醒：模拟器到点弹出通知（截图为证）；拒绝通知权限时软提醒正常并出现引导。
  8. 导出/导入：CSV 能在微信/Excel 打开；导出→清空→导入后数据与判定完全一致、无重复。
  9. 驾驶员（或其长辈）亲手完成一轮"录入 → 查看 → 修改 → 导出"试用，全程无需讲解。
  10. 适老化走查：无小于 14sp 文字；正文对比度 ≥ 7:1；可点元素达 5.2 尺寸；两步流程无手势依赖；颜色+文字双编码；系统字体 1.3x 不破版。
